# Medical Image Analysis

Uma plataforma dedicada à análise de imagens médicas, especialmente tomografias computadorizadas (CT Scans).

## Funcionalidades

- Faça upload de imagens de tomografia para análise.
- Processamento de imagens rápido e detalhado.
- Resultados apresentados com clareza e precisão.

## Como Usar

1. Faça upload de uma imagem de tomografia utilizando os formatos PNG, JPG ou JPEG.
2. Clique no botão **Analyze Image** para iniciar a análise.
3. Aguarde o processamento da imagem.
4. Visualize os resultados detalhados.

### Especificações dos Arquivos Aceitos

- **Formatos:** PNG, JPG, JPEG.
- **Tamanho máximo:** 10MB.
- **Resolução recomendada:** 512x512 pixels ou maior.
